# Sprint_7: API-тесты для сервиса «Яндекс.Самокат»

## Описание проекта

Проект содержит API-тесты для учебного сервиса «Яндекс.Самокат»:
- Создание курьера (7 тестов)
- Логин курьера (7 тестов)
- Создание заказа (5 тестов)
- Список заказов (2 теста)

**Итого: 21 тест, все проходят (100%).**

## Технологии

- Python 3.14
- Requests
- Pytest
- Allure Report
